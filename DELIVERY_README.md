# Delivery Package Guide

This file explains the contents of the final zip package.

## 1. Memoria

This is the full written report.

It should cover the motivation, state of the art, design, implementation, evaluation, and conclusions.

## 2. Presentation

This is the material used for the public defense.

It should explain the problem, the method, the pipeline, and the final result in a short visual format.


## 3. Code

The code is the implementation of the CSR pipeline.

Main locations:
- `src/pipeline/`: the pipeline steps
- `src/graph/`: workflow wiring
- `src/schemas/`: data models
- `tests/`: basic validation

## 4. Results

The results are stored as final artifacts generated by the last agent.

Main files:
- `docs/results.md`: result labels, real snapshots, and reproducibility note
- `data/processed/langgraph/<company>/agent_9/final_summary.md`: human-readable final outcome
- `data/processed/langgraph/<company>/agent_9/final_traceability_report.md`: claim-by-claim evidence trail
- `data/processed/langgraph/<company>/agent_9/final_report.json`: structured final output
- `data/processed/langgraph/<company>/agent_9/final_report.csv`: tabular final output

## 5. Where The Evidence Is

The main evidence for the final result is in the traceability report.

The most important evidence files are:
- `final_traceability_report.md`
- `final_report.json`
- `final_report.csv`

These files show the final claim labels, the evidence used, and the supporting justification.

## 6. Agent Documentation

Extra explanation for the pipeline is in:
- `code/docs/agents.md`

## 7. Notes On Reproducibility

The pipeline uses LLMs and live web search, so repeated runs can differ slightly.

The overall pattern usually stays the same, but one or two borderline labels can change between runs.
